# AURORA 盤面の当たり判定修正（2026-10-28）

720×960 の assets/aurora.webp に合わせて、液晶下の透明ステージを8本の上面として定義した。中央の347〜373pxは落とし口として開けている。手前のプラスチックに重なる金の装飾は釘扱いから除外し、残りの釘IDは維持した（411本）。

液晶の下隅は矩形ではなく、(188,464)→(264,504)、(456,504)→(532,464)の斜辺。旧矩形はステージの左入口を塞いでいた。

START の口・描画・入賞判定は engine.js の START を共有する。上から口を横切った玉のみ入賞し、左右の壁や下からの侵入は入賞しない。描画は pachinko-pocket.js の金の頬枠、奥行きのある口、下側の銘板で構成する。

物理更新は時間（最大1/240秒）と移動距離（玉半径の半分）の両方で細分化し、細い釘・ガイドのすり抜けを防ぐ。上面は低速時に跳ね返さず法線速度のみを止める。下側の玉を上面へ吸い上げない。

## 検証

- 30/60/120fpsで左右ステージから中央落とし口へ到達。
- 高速衝突、上面の表裏、斜め液晶下端、STARTの正面入賞・横/下/逆向きの拒否を回帰テスト。
- 盤面画像に実際のCanvas描画と軌跡を重ねて確認。
- ブラウザ用Chromiumが環境にないため、ブラウザでの実プレイは未確認。

## 入賞頻度への影響（要プレイ確認）

発射ゆらぎを-1〜1で等間隔に変えた各300発、120fps、13秒で計測。

| 発射強度 | START | 右大入賞口位置通過 | 停滞 |
| --- | --- | --- | --- |
| 30% | 173/300 | 41/300 | 0 |
| 45% | 221/300 | 6/300 | 0 |
| 90% | 0/300 | 300/300 | 0 |

ステージが玉を中央へ送るため、旧テストのSTART率4〜12%より大きく上昇する。旧率を維持するための見えない壁・乱数による取りこぼしは追加していない。旧率テストは左打ちで入賞可能・右打ちでSTARTに入りにくいという経路の検証に変更した。これは実機の入賞率を再現した値ではない。抽選確率1/99、入賞払い出し、役の抽選表は変更していないが、ゲームの消費・保留頻度は変わるため、マージ前にプレイ感を確認する。
