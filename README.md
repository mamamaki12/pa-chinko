# REEL ROOM v0.3.0

無料のパチンコ／パチスロ・シミュレーションWebアプリ。オリジナル機のパチンコ「AURORA」とパチスロ「ASTRAL」を収録しています。実在機の映像・音源や抽選仕様は使用していません。治療効果は検証していません。

## 起動

Node.js（検証用）とPython 3だけで利用できます。外部パッケージ、API、フォント配信は不要です。

```sh
npm start
# http://localhost:3000
npm test
npm run check
```

## 操作・機能

- パチンコ：発射ボタンで連続発射／停止。強度25〜100%（初期45%）。玉は外周レールを上り、強度に応じた位置で盤面に出ます（弱いと左、強すぎると右に流れて入賞しにくい）。ちょうどよい強さでのスタート入賞は打った玉の約6〜7%（250玉で約16回転）で、実機の甘デジの回り方に合わせています。重力、釘・外周・中央液晶・液晶上の屋根・入賞口へ寄せる透明なガイドとの衝突を固定120Hzで計算。発射に小さなばらつきがあります。スタート入賞で3玉。1/99の大当たりは実機のようなラウンド制で、右下の大入賞口（アタッカー）が開き、発射強度を強くした右打ちで入れた玉1つにつき8玉を払い出します（1ラウンドは10個入るか30秒で閉じ、2秒あけて次へ。4ラウンドで最大320玉）。液晶にラウンド・カウントと「右打ち ▶」を表示し、ふだんの遊技で発射強度を70%以上にすると、実機のように液晶へ「◀ 左打ち」を出します。大当たり中は保留の抽選を待ちます。抽選は最大4つ保留し、液晶左下の4つのランプで表示（5つ目以降の入賞は3玉のみ）。変動時間は保留数で変わり（外れ：保留0で5秒、1〜2で4秒、3以上で2.5秒）、当たりと外れの約1/15でリーチ（左右の数字がそろい、中央がゆっくり回る）。リーチの延長は「控えめな演出」または動きを減らす設定で2.5秒、それ以外は4秒。保留ランプは1色で当たりを予告せず、リーチ外れの中央は1つ違いの数字で止めません。リーチの途中で液晶に「PUSH!」が出て、台の中央手前のボタン（チャンスボタン）が光ります。ボタンをタップ／クリック（またはEnterキー）すると中央の数字が止まって結果が出ます（押さなくても3.5秒で自動で止まります）。ボタン演出は当たり・外れに関係なくすべてのリーチで同じように出るので、当たりの予告にはなりません（結果は抽選のときに決まっていて、押し方では変わりません）。遊技台の機構を簡略化した独自仕様です。
- パチスロ：筐体イラスト（`assets/astral.webp`）はそのままに、リール窓のまわりだけを実機風に `slot-view.js` で描画します（1本に3コマ見えるリール、左のメダリオンにBETランプ3・2・1、右にSTART／REPLAY／WAITランプ、窓の下のプレートに7セグのCREDIT・PAYOUT）。リール帯は図柄（白い縁取りと黒い輪郭の太い印刷風。金の縁・紺・四方に光る星などASTRALのモチーフで飾った7、紺の板に銀文字のBAR、金のメダルつきREPLAY、切ったスイカ、つやのあるチェリー、星を刻んだベル）ごと一度だけ画面外に描き、毎フレーム細い帯に切って円筒に巻き付けるので、実機のドラムのように上下で図柄が曲がって暗くなります。回転中は縦に流れるブレ、背面の3つのランプで各段が明るく、ドラムの縁・窓枠の影・ガラスの映り込みもつけています。ランプはメダリオンにはめた丸いレンズで、消灯中はくすんだ黒、点灯するとその色に光ります（WAITは4.1秒ウェイト中に点灯）。プレートの文字の書体は筐体の彫り文字に合わせた Cinzel／Cinzel Decorative（SIL Open Font License、`assets/fonts/` に同梱）です。筐体に描かれたレバー（左の黒いノブ）・MAX BET（右の銀のドーム）・停止ボタンを直接タップ／クリックして操作します（パチスロでは画面下の操作ボタンは出しません）。押すとへこみ、押せるときは光ります。盤面のレバー・MAX BET・停止ボタンは直接タップ／クリックでき、押すとへこみ、レバーは下に倒れます。MAX BETで3枚を投入（未投入でレバーを叩くと自動で投入）。レバーを叩くと、その時点で役を抽選します（独自の表、16384分の：BIG 40、スイカ 200、チェリー 400、ベル 1800、リプレイ 2240、残りは外れ）。実機と同じく1ゲームは4.1秒より短くならず、前のゲームの開始から4.1秒たつ前にレバーを叩くと、役はその場で抽選し、リールは4.1秒たってから回ります（ウェイト）。個別STOPを押すと、その時に中央へ来る図柄から最大4コマ（約0.2秒以内）すべらせて、リールを減速させずにピタッと止め、成立した役を中央1ラインに引き込み、成立していない役は外します。リールは左・中・右で別の21図柄配列。ベルとリプレイはどこで押しても揃い、7・スイカ・左チェリーは押す位置によって取りこぼします（持ち越しなし）。配当は7揃いでBIGボーナス（実機のAタイプのように、7揃い自体の払い出しはなく、BIG中は毎ゲームどこで押しても15枚のベルが揃い、合計150枚を払い出すと終了。液晶に「BIG BONUS」と獲得枚数を表示）、スイカ10枚、ベル8枚、左チェリー2枚、リプレイは次ゲームのメダル不要、BARは配当なし。払い出しは実機のようにPAYOUTとCREDITを1枚ずつ数えて増やし（1秒に12枚、動きを減らす設定では一度に）、数え終わるまで次のゲームは始められません。BIG以外のボーナス、AT、RTは未実装。ボーナスの持ち越しと告知ランプは、揃えるまで遊び続けたくなる仕組みなので入れていません。
- 液晶のキャラクター：AURORAには「ハナ」（ピンクの髪・花飾り）、ASTRALには「ソラ」（銀青の髪・星飾り）が液晶の中にいて、状況に合わせて動き、吹き出しでしゃべります（`lcd-character.js`、Canvasで描いたオリジナルのミニキャラ。筐体の女の子に合わせた衣装・ティアラ／花冠・羽で、丸くやさしい目（大きな瞳とハイライト）・ω口・ほっぺの赤みで、線画・影・ハイライトまで描き込み、画面外に描いてから白いふちの光をつけて液晶に重ねます）。待機中はまばたき・ゆらゆら・ときどき雑談（深呼吸や水分補給など）、抽選中・リール回転中は画面を見守り、リーチ・当たり・はずれ、パチスロのリプレイ・ベル・チェリー・スイカ・7揃い（BIG）、休憩前・休憩中・おかえり・終了のあいさつに反応します。反応は結果が出たあと（またはリーチが出たあと）だけで、レバーや変動開始の反応はどのゲームでも同じ候補から選ぶので、当たりの予告にはなりません。惜しさを強調するセリフや、続けて遊ぶようあおるセリフは入れていません。当たりのあとは休憩を勧める一言が続きます。サウンドONのときは、文字送りに合わせて合成の短い声（ピコピコ音）が鳴ります。控えめな演出ではきらめきを弱く、動きを減らす設定では体の動きを止め、セリフを一度に表示します。
- Space：発射／レバー、B：MAX BET、1・2・3：各リール停止（入力欄、ボタン、ダイアログを操作中は無効）。
- 筐体はオリジナルのAI生成イラスト（`assets/aurora.webp`・`assets/astral.webp`、液晶とリール窓を透過）。その下に液晶（`assets/lcd-illustration.jpg`をゆっくり移動・拡大、保留ランプは液晶の左下）とリールを、上に釘・玉・ガラスの反射をCanvas 2Dで描画。玉は左上から光が当たる鏡面の鋼球として描き、手前の受け皿とパネル、中央手前のボタンはガラスより前にあるので、玉・釘・ガラスの反射はボタンに重ねず、ガラスの範囲だけに描きます。液晶の数字は縁取りと立体感のある書体で、回転中は縦にスクロールして残像がつき、減速して止まると小さく弾みます（どの数字で止まるかは抽選結果だけで決まり、そろいそうな数字の前で遅くなる演出はしません）。液晶の背景は実機の待機・変動画面のように、イラストの中を寄ったり流したりしながら約7秒ごとに場面が切り替わり（光が横切るつなぎ）、2層の雲が流れ、花びらが舞い、流れ星や光の筋が動きます。抽選中は背景の動きが速くなります（当たり外れに関係なくすべての抽選で同じ）。リーチ中と当たりの直後は台のまわりのランプが光ります。控えめな演出がONのときは動きを少し遅く・光を弱くし（場面切り替えの光は出さない）、ランプは流れずにゆっくり明滅します。端末の「視差効果を減らす（動きを減らす）」設定では、背景（1枚の静止画）・スクロール・弾み・ランプの明滅を止めます。効果音は `sound.js` がWeb Audioでその場で合成します（音声ファイルなし）。発射音、釘に当たる音、スタート入賞のチャイム、液晶の回転音と停止音、リールの回転音、停止ボタンの音、払出音。当たりの音は短く控えめにしています。音量は設定に従います。音は初期OFF、光と動きを抑える設定は初期ON。
- 5／10／15分の自動休憩。休憩・設定・記録の表示中は遊技と時間を凍結。タブを離れたときも中断。発射の再開は手動です。
- 「今日はここまで」→「記録して終了」で日時、遊技時間、機種、消費数、払出数をこのブラウザのlocalStorageに直近50件保存。休憩画面では任意で「続けたい気持ち」（1〜5）と200字までのメモも残せます（入力しなくても終了できます）。JSON出力・削除に対応。終了せずタブを閉じると今回の記録は残りません。ブラウザ間の同期、My海馬への自動同期はありません。
- 左の「THIS WEEK」に今週（月曜0時から）の遊技時間を表示。設定で1週間の目安（1〜7時間）を決めると、超えたときに控えめなお知らせを1回だけ出します。遊技は止めず、休憩や終了を選びやすくするための表示です。プレイ記録には直近4週の合計・回数・気持ちの平均を表示。集計は保存済みの記録から計算するため、記録を削除すると合計も消えます。
- 現金、課金、換金、広告、外部送信はありません。残高はリロードで初期値に戻ります。

## 対象と限界

依存症の治療・回復を保証するものではありません。リアルな遊技表現は遊技欲求を強める可能性があります。欲求が強まる場合は中断してください。長時間継続を促すミッションや通知は設けていません。

本版は動作するオリジナルの試作です。実機相当の3Dモデル、映像演出、音響、機構の完全再現には未到達です。スマートフォンを含むCanvas対応ブラウザ向け。遊技台は画面の高さに合わせて大きく表示します（パソコンでは台と操作ボタンが1画面に収まる大きさ、スマートフォンでは画面の幅いっぱい）。

筐体と液晶のイラストはAIで生成したオリジナル画像で、実在の機種・作品のロゴやキャラクターではありません。元画像はMy海馬（`20_開発/進行中/pa-chinko/`）に保存しています。

## 検証

配当、パチスロの役抽選の出現数、すべり制御（全押し位置・全停止順で最大4コマ、成立していない役が揃わないこと）、抽選、釘反射、外周、中央液晶衝突、レール発射、釘配置、入賞判定、乱数の範囲、週の区切りと集計、ふりかえりの値の整形、液晶キャラクターのセリフ（あおる言葉がないこと・優先度・文字送り）をNodeで検証。Chromiumで発射・停止・休憩・終了記録・リール停止・設定・再読み込み後の保存・390px幅の横はみ出しを確認。iOS Safariの実機性能・音響は未検証。
