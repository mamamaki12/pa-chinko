# REEL ROOM v0.2.0

無料のパチンコ／パチスロ・シミュレーションWebアプリ。オリジナル機「蒼海の記憶」と「MIDNIGHT 7」を収録しています。実在機の映像・音源や抽選仕様は使用していません。治療効果は検証していません。

## 起動

Node.js（検証用）とPython 3だけで利用できます。外部パッケージ、API、フォント配信は不要です。

```sh
npm start
# http://localhost:3000
npm test
npm run check
```

## 操作・機能

- パチンコ：発射ボタンで連続発射／停止。強度25〜100%。重力、釘・外周・中央液晶との衝突を固定120Hzで計算。発射速度に小さなばらつきがあります。スタート入賞で3玉、1/99で300玉を払出。遊技台の機構を簡略化した独自仕様です。
- パチスロ：レバーで3枚投入し、個別STOPで停止。21図柄の回転位置から3コマ先の整数位置まで減速します。中央1ラインの7揃い150枚、BAR30枚、ベル15枚、スイカ10枚、チェリー8枚、REPLAY3枚、左チェリーのみ2枚。実機の役抽選、ボーナス、AT、RT、滑り制御は未実装。
- Space：発射／レバー、1・2・3：各リール停止（入力欄、ボタン、ダイアログを操作中は無効）。
- 金属枠、ガラス反射、海中背景、玉、独自図柄をCanvas 2Dで描画。効果音は `sound.js` がWeb Audioでその場で合成します（音声ファイルなし）。発射音、釘に当たる音、スタート入賞のチャイム、液晶の回転音と停止音、リールの回転音、停止ボタンの音、払出音。当たりの音は短く控えめにしています。音量は設定に従います。音は初期OFF、光と動きを抑える設定は初期ON。
- 5／10／15分の自動休憩。休憩・設定・記録の表示中は遊技と時間を凍結。タブを離れたときも中断。発射の再開は手動です。
- 「今日はここまで」→「記録して終了」で日時、遊技時間、機種、消費数、払出数をこのブラウザのlocalStorageに直近50件保存。JSON出力・削除に対応。終了せずタブを閉じると今回の記録は残りません。ブラウザ間の同期、My海馬への自動同期はありません。
- 現金、課金、換金、広告、外部送信はありません。残高はリロードで初期値に戻ります。

## 対象と限界

依存症の治療・回復を保証するものではありません。リアルな遊技表現は遊技欲求を強める可能性があります。欲求が強まる場合は中断してください。長時間継続を促すミッションや通知は設けていません。

本版は動作するオリジナルの試作です。実機相当の3Dモデル、映像演出、音響、機構の完全再現には未到達です。スマートフォンを含むCanvas対応ブラウザ向け。

## 検証

配当、抽選、釘反射、外周、中央液晶衝突、乱数の範囲をNodeで検証。Chromiumで発射・停止・休憩・終了記録・リール停止・設定・再読み込み後の保存・390px幅の横はみ出しを確認。iOS Safariの実機性能・音響は未検証。

## 配信

Sitesの本人限定公開を使用。`.openai/hosting.json` がSite IDと静的配信ディレクトリを保持します。公開用の4ファイルは `dist/` に同期してからコミットします。
