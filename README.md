# REEL ROOM v0.3.0

無料のパチンコ／パチスロ・シミュレーションWebアプリ。オリジナル機のパチンコ「AURORA」とパチスロ「ASTRAL」を収録しています。実在機の映像・音源や抽選仕様は使用していません。治療効果は検証していません。

## 起動

Node.js（検証用）とPython 3だけで利用できます。外部パッケージ、API、フォント配信は不要です。

```sh
npm start
# http://localhost:3000
npm test
npm run check
```

## 操作・機能

- パチンコ：発射ボタンで連続発射／停止。強度25〜100%（初期45%）。玉は外周レールを上り、強度に応じた位置で盤面に出ます（弱いと左、強すぎると右に流れて入賞しにくい）。重力、釘・外周・中央液晶・液晶上の屋根・入賞口へ寄せる透明なガイドとの衝突を固定120Hzで計算。発射に小さなばらつきがあります。スタート入賞で3玉、1/99で300玉を払出。抽選は最大4つ保留し、液晶左下の4つのランプで表示（5つ目以降の入賞は3玉のみ）。変動時間は保留数で変わり（外れ：保留0で5秒、1〜2で4秒、3以上で2.5秒）、当たりと外れの約1/15でリーチ（左右の数字がそろい、中央がゆっくり回る）。リーチの延長は「控えめな演出」または動きを減らす設定で2.5秒、それ以外は4秒。保留ランプは1色で当たりを予告せず、リーチ外れの中央は1つ違いの数字で止めません。遊技台の機構を簡略化した独自仕様です。
- パチスロ：レバーで3枚投入すると、その時点で役を抽選します（独自の表、16384分の：BIG 40、スイカ 200、チェリー 400、ベル 1800、リプレイ 2240、残りは外れ）。個別STOPを押すと、3コマ先から最大4コマすべらせて、成立した役を中央1ラインに引き込み、成立していない役は外します。リールは左・中・右で別の21図柄配列。ベルとリプレイはどこで押しても揃い、7・スイカ・左チェリーは押す位置によって取りこぼします（持ち越しなし）。配当は7揃い150枚、スイカ10枚、ベル8枚、左チェリー2枚、リプレイは次ゲームのメダル不要、BARは配当なし。ボーナスゲーム、AT、RTは未実装。
- Space：発射／レバー、1・2・3：各リール停止（入力欄、ボタン、ダイアログを操作中は無効）。
- 筐体はオリジナルのAI生成イラスト（`assets/aurora.webp`・`assets/astral.webp`、液晶とリール窓を透過）。その下に液晶（`assets/lcd-illustration.jpg`をゆっくり移動・拡大、保留ランプは液晶の左下）とリールを、上に釘・玉・ガラスの反射をCanvas 2Dで描画。控えめな演出がONのときは液晶を止め、光を弱めます。効果音は `sound.js` がWeb Audioでその場で合成します（音声ファイルなし）。発射音、釘に当たる音、スタート入賞のチャイム、液晶の回転音と停止音、リールの回転音、停止ボタンの音、払出音。当たりの音は短く控えめにしています。音量は設定に従います。音は初期OFF、光と動きを抑える設定は初期ON。
- 5／10／15分の自動休憩。休憩・設定・記録の表示中は遊技と時間を凍結。タブを離れたときも中断。発射の再開は手動です。
- 「今日はここまで」→「記録して終了」で日時、遊技時間、機種、消費数、払出数をこのブラウザのlocalStorageに直近50件保存。休憩画面では任意で「続けたい気持ち」（1〜5）と200字までのメモも残せます（入力しなくても終了できます）。JSON出力・削除に対応。終了せずタブを閉じると今回の記録は残りません。ブラウザ間の同期、My海馬への自動同期はありません。
- 左の「THIS WEEK」に今週（月曜0時から）の遊技時間を表示。設定で1週間の目安（1〜7時間）を決めると、超えたときに控えめなお知らせを1回だけ出します。遊技は止めず、休憩や終了を選びやすくするための表示です。プレイ記録には直近4週の合計・回数・気持ちの平均を表示。集計は保存済みの記録から計算するため、記録を削除すると合計も消えます。
- 現金、課金、換金、広告、外部送信はありません。残高はリロードで初期値に戻ります。

## 対象と限界

依存症の治療・回復を保証するものではありません。リアルな遊技表現は遊技欲求を強める可能性があります。欲求が強まる場合は中断してください。長時間継続を促すミッションや通知は設けていません。

本版は動作するオリジナルの試作です。実機相当の3Dモデル、映像演出、音響、機構の完全再現には未到達です。スマートフォンを含むCanvas対応ブラウザ向け。

筐体と液晶のイラストはAIで生成したオリジナル画像で、実在の機種・作品のロゴやキャラクターではありません。元画像はMy海馬（`20_開発/進行中/pa-chinko/`）に保存しています。

## 検証

配当、パチスロの役抽選の出現数、すべり制御（全押し位置・全停止順で最大4コマ、成立していない役が揃わないこと）、抽選、釘反射、外周、中央液晶衝突、レール発射、釘配置、入賞判定、乱数の範囲、週の区切りと集計、ふりかえりの値の整形をNodeで検証。Chromiumで発射・停止・休憩・終了記録・リール停止・設定・再読み込み後の保存・390px幅の横はみ出しを確認。iOS Safariの実機性能・音響は未検証。

## 配信

Sitesの本人限定公開を使用。`.openai/hosting.json` がSite IDと静的配信ディレクトリを保持します。公開用の6ファイル（index.html、style.css、app.js、engine.js、sound.js、journal.js）と `assets/` は `dist/` に同期してからコミットします。
