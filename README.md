# REEL ROOM v0.3.0

無料のパチンコ／パチスロ・シミュレーションWebアプリ。オリジナル機のパチンコ「AURORA」とパチスロ「ASTRAL」を収録しています。実在機の映像・音源や抽選仕様は使用していません。治療効果は検証していません。

## 起動

Node.js（検証用）とPython 3だけで利用できます。外部パッケージ、API、フォント配信は不要です。

```sh
npm start
# http://localhost:3000
npm test
npm run check
```

## 操作・機能

- パチンコ：発射ボタンで連続発射／停止。強度25〜100%（初期45%）。玉は外周レールを上り、強度に応じた位置で盤面に出ます（弱いと左、強すぎると右に流れて入賞しにくい）。ちょうどよい強さでのスタート入賞は打った玉の約6〜7%（250玉で約16回転）で、実機の甘デジの回り方に合わせています。重力、釘・外周・中央液晶・液晶上の屋根との衝突を固定120Hzで計算。START入賞口（ヘソ）は命釘の真下に左右の壁がある袋で、命釘の間から入った玉だけが入賞します。発射に小さなばらつきがあります。スタート入賞で3玉。1/99の大当たりは実機のようなラウンド制で、右下の大入賞口（アタッカー）が開き、発射強度を強くした右打ちで入れた玉1つにつき8玉を払い出します（1ラウンドは10個入るか30秒で閉じ、2秒あけて次へ。4ラウンドで最大320玉）。液晶にラウンド・カウントと「右打ち ▶」を表示し、ふだんの遊技で発射強度を70%以上にすると、実機のように液晶へ「◀ 左打ち」を出します。大当たり中は保留の抽選を待ちます。抽選は最大4つ保留し、液晶左下の4つのランプで表示（5つ目以降の入賞は3玉のみ）。変動時間は保留数で変わり（外れ：保留0で5秒、1〜2で4秒、3以上で2.5秒）、当たりと外れの約1/15でリーチ（左右の数字がそろい、中央がゆっくり回る）。リーチの延長は「控えめな演出」または動きを減らす設定で2.5秒、それ以外は4秒。リーチには実機のように種類があり、どれもノーマルリーチから始まって、途中で「流星リーチ」（液晶が夜空になり流れ星が降る。左右の数字は上の隅に小さくなり、中央の数字が大きくなる）、さらに「天空城リーチ」（お城の金色の光・回る光の筋・舞い上がる光の粒・虹色のふち）へ発展するか、ノーマルから「バトルリーチ」へ発展することがあります。バトルリーチでは数字が左上に小さく寄り、ハナと敵の「雲のいたずら精 モクモ」が登場して VS の文字が出たあと、花びらの魔法とモクモの風を撃ち合います（ここまではどの抽選でも同じ）。ボタンを押すと両方の技がぶつかり、当たりならハナの必殺技でモクモが目を回して飛んでいき「勝利」の文字のあと数字が揃います。外れならモクモが手を振って去り、ハナは落ち着いて見送ります（負けを強く見せないため、ハナが倒れたり落ち込んだりはしません）。当たりの一部（バトルで当たるときの10%）は、いったん外れと同じ見せ方が始まってから1秒でハナが光り、金色の光で復活して必殺技で勝つ「復活演出」になります。復活は真ん中の数字が止まる前にだけ起き、外れのときには起きないので、数字が外れで止まったらそれで終わりです（外れの見せ方が復活になる割合は約15%）。キャラの絵は `assets/battle/` の生成画像から `scripts/make-battle-sprites.py` で作った `assets/battle-sprites.webp`、演出は `battle-fx.js`、専用のBGM・効果音・台のLEDの光り方があります。`?reach=battle`（`?reach=battle-revive` で当たりのときは復活）を付けると、リーチがすべてバトルになり見た目を確認できます（当たる確率は変わりません）。発展の瞬間は白いフラッシュとリーチ名の帯が出て、キャラが驚き、発展の音が鳴り、台のLEDも青（流星）・虹と金（天空城）に変わります（控えめな演出では長さを短く・光を弱く、動きを減らす設定では止まった絵）。リーチの文字とPUSHボタンの色（青・緑・赤）も変わります。種類と色は抽選の結果が決まったあとに `engine.js` の表（`REACH_PICK`・`REACH_COLOR`）から選ぶだけなので、当たる確率（1/99）は変わりません。当たりのときほど長いリーチ・赤を選びやすくしているので、リーチの当たる割合は ノーマル約2%・流星約19%・天空城約43%・バトル約64%、青約4%・緑約13%・赤約46% です（`reachTrust` で計算。遊技台の説明にも同じ数字を載せています）。設定の「リーチ・予告演出」を「いつも同じ」にすると、すべてのリーチがノーマル・ピンクになり、予告も出ず、当たりを予告しません。保留ランプは1色で当たりを予告せず、リーチ外れの中央は1つ違いの数字で止めません。リーチの途中で液晶に「PUSH!」が出て、台の中央手前のボタン（チャンスボタン）が光ります。ボタンをタップ／クリック（またはEnterキー）すると中央の数字が止まって結果が出ます（押さなくても3.5秒で自動で止まります）。ボタン演出は当たり・外れに関係なくすべてのリーチで出ます（色はリーチの色。結果は抽選のときに決まっていて、押し方では変わりません）。遊技台の機構を簡略化した独自仕様です。
- パチスロ：筐体イラスト（`assets/astral.webp`）はそのままに、リール窓のまわりだけを実機風に `slot-view.js` で描画します（1本に3コマ見えるリール、左のメダリオンにBETランプ3・2・1、右にSTART／REPLAY／WAITランプ、窓の下のプレートに7セグのCREDIT・PAYOUT）。リール帯は空色の紙に雲と星を刷った柄で、図柄（実機の写真を参考に、リール幅いっぱいの太い7に筐体の女の子の絵を刷り込み、金と紺のふち。金のふちの黒いBARに赤い文字、青い宝石のリプレイ、横に広い金のベル、切ったスイカ、つやのあるチェリー））ごと一度だけ画面外に描き、毎フレーム細い帯に切って円筒に巻き付けるので、実機のドラムのように上下で図柄が曲がって暗くなります。回転中は縦に流れるブレ、背面の3つのランプで各段が明るく、ドラムの縁・窓枠の影・ガラスの映り込みもつけています。ランプはメダリオンにはめた丸いレンズで、消灯中はくすんだ黒、点灯するとその色に光ります（WAITは4.1秒ウェイト中に点灯）。プレートの文字の書体は筐体の彫り文字に合わせた Cinzel／Cinzel Decorative（SIL Open Font License、`assets/fonts/` に同梱）です。筐体に描かれたレバー（左の黒いノブ）・MAX BET（右の銀のドーム）・停止ボタンを直接タップ／クリックして操作します（パチスロでは画面下の操作ボタンは出しません）。押すとへこみ、押せるときは光ります。盤面のレバー・MAX BET・停止ボタンは直接タップ／クリックでき、押すとへこみ、レバーは下に倒れます。MAX BETで3枚を投入（未投入でレバーを叩くと自動で投入）。レバーを叩くと、その時点で役を抽選します（独自の表、16384分の：BIG 40、スイカ 200、チェリー 400、ベル 1800、リプレイ 2240、残りは外れ）。実機と同じく1ゲームは4.1秒より短くならず、前のゲームの開始から4.1秒たつ前にレバーを叩くと、役はその場で抽選し、リールは4.1秒たってから回ります（ウェイト）。個別STOPを押すと、その時に中央へ来る図柄から最大4コマ（約0.2秒以内）すべらせて、リールを減速させずにピタッと止め、成立した役を有効ラインのどれか1本に引き込み、成立していない役はどのラインにも揃えません。有効ラインはMAX BET（3枚）で横3本（上段・中段・下段）と斜め2本の5ラインすべてで、どのラインに揃っても払い出し、揃ったラインは窓の左右の矢印ランプが金色に光り、図柄の上に金の線が引かれます（`engine.js` の `LINES`・`settle`）。すべり制御は、まだ止めていないリールをどこで押されても成立していない役が揃わない止め方を先に選び、そのうえで成立役が揃いやすい止め方を選びます。リールは左・中・右で別の21図柄配列。ベルとリプレイはどこで押しても揃い、7・スイカ・左チェリーは押す位置によって取りこぼします（持ち越しなし）。配当は7揃いでBIGボーナス（実機のAタイプのように、7揃い自体の払い出しはなく、BIG中は毎ゲームどこで押しても15枚のベルが揃い、合計150枚を払い出すと終了。液晶に「BIG BONUS」と獲得枚数を表示）、スイカ10枚、ベル8枚、左チェリー2枚（ラインごとなので、左リールの上段・下段に止まる角チェリーは2ライン分の4枚）、リプレイは次ゲームのメダル不要、BARは配当なし。払い出しは実機のようにPAYOUTとCREDITを1枚ずつ数えて増やし（1秒に12枚、動きを減らす設定では一度に）、数え終わるまで次のゲームは始められません。BIG以外のボーナス、AT、RTは未実装。ボーナスの持ち越しと告知ランプは、揃えるまで遊び続けたくなる仕組みなので入れていません。
- 液晶のキャラクター：AURORAには「ハナ」（ピンクの髪・花飾り）、ASTRALには「ソラ」（銀青の髪・星飾り）が液晶の中にいて、状況に合わせて動き、液晶にセリフの文字だけを出してしゃべります（吹き出しの枠はなく、白い文字にキャラの色のふちどり。`lcd-character.js` の反応制御と `navigator-art.js` の描画。銀青・星飾りのソラ、ピンク・花飾りのハナを、繊細な髪の流れと柔らかな顔のオリジナルイラストに更新。透明な画像に通常・喜び・驚き・休憩の4表情を収録し、足元の位置を揃えて短く重ねながら切り替えます。ときどきまばたきし、しゃべっている間は文字送りに合わせて口が開いたり閉じたりします（句読点では閉じる）。頭・腕・足・羽・髪・スカートがパーツごとに動き、反応ごとに動きが変わります（見守り：画面のほうへ首をかしげて足をぶらぶら、うなずき、手を振る：上げた腕を肩から振る、拍手：腕を上げ下げして小さく跳ねる、喜び：腕を上げてぴょんぴょん跳ね、跳ぶたびに足が外へ出て着地でつぶれる・大当たりやBIGは最初にくるっと1回転して前に出る、リーチ・大当たり開始：驚いて頭をのけぞらせて跳ね、そのあと足踏みして手が震える、おじぎ、休憩中はうとうと首をかたむける）。しゃべっている間は首と手も小さく動きます。何もないときは6.5秒ごとくらいに、ぴょんと跳ねる・左右に揺れる・くるっと回る・伸び・リズムに乗る・振り向くといった小さな仕草をします（抽選中・おしゃべり中はしない）。まわりには、喜び・拍手のきらめき、リーチ・大当たり開始の「！」、手を振るときの音符、休憩中の「z」が出ます。画像の読込中・読込失敗時は従来のCanvasキャラを表示）。待機中はゆっくりした揺れ・ときどき雑談（深呼吸や水分補給など）、抽選中・リール回転中は画面を見守り、リーチ・当たり・はずれ、パチスロのリプレイ・ベル・チェリー・スイカ・7揃い（BIG）、休憩前・休憩中・おかえり・終了のあいさつに反応します。反応は結果が出たあと（またはリーチが出たあと・リーチが流星や天空城に発展したあと）だけで、レバーや変動開始の反応はどのゲームでも同じ候補から選ぶので、当たりの予告にはなりません。惜しさを強調するセリフや、続けて遊ぶようあおるセリフは入れていません。当たりのあとは休憩を勧める一言が続きます。サウンドONのときは、文字送りに合わせて合成の短い声（ピコピコ音）が鳴ります。控えめな演出ではきらめきと跳ね方を弱く、動きを減らす設定では体の動き・まばたき・口パク・仕草を止め、セリフを一度に表示します。
- 台の部品：台を1枚の絵としてではなく、要素ごとの部品として `cabinet-parts.js` で管理します。AURORAはLED・釘・ガイドレール・START入賞口・アタッカー・チャンスボタン・発射ハンドル・保留ランプ・液晶・盤面ガラス、ASTRALはLED・液晶・リール窓・リール・ベット/START/REPLAY/WAITランプ・クレジットと払い出しの表示器・レバー・MAX BET・停止ボタン。どの部品も id・種類・名前・形（位置）・状態（表示・点灯・開閉）を持ち、`parts.set('attacker',{open:true})`・`parts.set('nail-012',{visible:false})`（その釘は当たり判定からも外れる）のように id・種類・グループで切り替えられます。描画とパチスロのランプの点灯はこの状態を読みます。ページを `?parts` 付きで開くと、全部品の輪郭とidを台の上に表示します。
- 台のLED：筐体イラストに描かれたLEDの部分（AURORA 21か所、ASTRAL 16か所）を `cabinet-leds.js` の多角形で部品として切り出し、その中の明るく色のついた画素だけを点灯・消灯させます（画面全体を光らせる演出はやめました）。部品ごとに 消灯 / 点灯 / 点滅 / 呼吸（ゆっくり明滅） / 流れる光 と明るさ・色（虹色も）を持ち、id・グループ（上・サイド・前面など）・全部で指定できます。場面ごとの光り方（待機・抽選中・リーチ・流星リーチ・天空城リーチ・ボタン・大当たり・払い出し・リール回転・リプレイ・BIG・ボーナス開始のファンファーレ・ボーナス終了）も同じファイルの表で決めています。点滅は1秒に3回より速くしません。控えめな演出では点滅を呼吸に変えてゆっくりにし、動きを減らす設定では止めます。設定の「台のLED」で 演出に合わせて光る / いつも点灯 / 消灯 を選べます。ページを `?leds=reach` のように開くと、その場面の光り方のまま確認できます。
- 液晶の背景（`lcd-scenes.js`）：実機の背景ステージのように、構図の違う「舞台」を切り替えます。舞台は、液晶の絵そのもの（天空城・女神、それぞれ数通りのカメラ）、絵から切り出した城・浮島・水晶・女神を使った新しい眺め（雲海の彼方の天空城・鏡の湖の天空城・浮島の群れ・水晶の浮島・女神の見守る空）、そして同じ画風で生成した追加の絵16枚（雲海を飛ぶ・空の回廊・空の鯨・光の大門・塔の街・空中庭園・天への階段・女神の間・水晶の洞窟・世界樹・鏡の湖・桜の並木・星夜の天空城・夕焼けの浮島・オーロラの空・月の道。`assets/lcd-stages/original/` が生成したままの 1672×941、アプリが読むのは 1024×576 に縮めた `assets/lcd-stages/<id>.webp`。`IMAGE_STAGES` にカメラと合う時間帯を登録する。液晶の絵のあとに読み込み、読み込みが終わるまでその舞台は出ない）です。描画コードで作った舞台（雲海を飛ぶ・空の鯨・竜・魔法陣・桜並木・海底・星の鉄道など38種類、`DRAWN`）も残していますが、絵との差が大きいので `DRAWN_ON` が false のあいだは出しません。舞台ごとに合う「時間帯」（昼・朝焼け・夕焼け・黄昏・夜・月夜・桜色・黄金・星雲・極夜・白銀・翡翠。空の色・太陽か月・星が変わる）と、「天気」（花びら・雪・光の粒・蛍・羽根・きらめき・泡・光の雨・結晶・紅葉・火の粉）・「空の出来事」（光の筋・流れ星・オーロラ・満月・虹・灯籠・鳥の群れ・花火・天の川・光輪）の組を2つずつ付けて背景にしています（昼の花火・夜の虹のような合わない組み合わせは除く）。番号と名前（例：「月夜の鏡の湖の天空城・雪と流れ星」）は固定の乱数で決まるので、どの端末でも同じです。台ごとに山札をシャッフルし（AURORAは暖かい色の空、ASTRALは夜や星の空が中心）、全部出るまで同じ背景は出ず、同じ舞台が続けて出ないように並べます。同じ背景を状態ごとに使い回し、待機中は約7秒ごと、変動が始まるとき、リーチ（流れ星・オーロラ・天の川・光輪の空）と大当たり中（光の筋・灯籠・花火・光輪の空）に切り替わります。背景は画面に出ている状態で変わるだけで、当たりの予告にはなりません。控えめな演出では粒を減らして切り替わりの光を出さず、動きを減らす設定では止まった背景になります。`?scene=番号` で1つの背景に固定して確認できます。
- 予告（`notice-fx.js`）：実機のように、変動の最初（パチンコは抽選の開始、パチスロはレバーON）に予告が出ることがあります。種類は群予告（蝶・鳥・花吹雪・星の群れが液晶を横切る）、セリフ予告（「なにか来そう…」〜「激アツ!!」）、カットイン（斜めの帯に「CHANCE」〜「超激アツ」）、ステージチェンジ（光が横切って背景がリーチ用の背景に、金ならお祭りの背景に変わる）の7種類で、色は青・緑・赤・金の4色（全28通り）。予告と色は抽選（パチスロは役の抽選）のあとに `engine.js` の表（`NOTICE_PICK`・`NOTICE_COLOR`）から選ぶだけなので、確率は変わりません。当たりのときほど出やすく、出たときに当たる割合（`noticeTrust`）はパチンコで予告全体 約6%、青約2%・緑約6%・赤約24%・金約83%、ステージチェンジ約38%。パチスロではBIGが予告全体 約1.5%、赤約8%・金約68%（スイカ・チェリーのときにも出やすい）。出ると短い効果音が鳴り、キャラが驚きます。設定の「リーチ・予告演出」を「いつも同じ」にすると予告は出ません。控えめな演出では数を減らして光を弱く、動きを減らす設定では止まった絵になります。
- 保留の色（色保留）：実機のように入賞したときに抽選し、保留ランプの玉に色が付くことがあります。色は白・青・緑・赤・金・虹で、当たる割合は白約0.3%・青約5%・緑約21%・赤約50%・金約85%・虹は当たり確定（`engine.js` の `HOLD_PICK`。実機の調査値 青5〜15%・緑10〜38%・赤40〜60%・金77〜96% を目安にしました）。色は抽選のあとに選ぶだけで当たる確率（1/99）は変わりません。変動中の保留は数字の下に出し、変動の始めに色が上がることがあります（保留変化）。「いつも同じ」ではすべて白です。リーチが外れたときは、止まった数字を1秒見せてから次の変動に移ります。ページに `?hold=red` などを付けると、保留の色をその色にして見た目を確かめられます。
- 当たりの演出（`celebration.js`）：パチスロで7が揃ってBIGが始まったとき、パチンコで数字が揃って大当たりになったときに、実機の当たり演出のような約5秒のショーを出します。液晶が1回だけ白く光り、金色の光の筋が回り、光の輪が広がり、花火と紙吹雪が舞う中で「777」「BIG BONUS」（パチンコは「大当たり」「JACKPOT」）の金文字が大きく飛び込んで弾み、光の帯が文字を横切ります。リールの中段の7（パチンコは揃った数字）は光って脈打ち、最初に光がラインを走ります。台のLEDは「ファンファーレ」の場面（上は金色、液晶まわりは白で点滅、サイドは虹色が流れる）になり、ブラスとティンパニ、シンバル、鐘のオリジナルのファンファーレ（約3.5秒、`music.js` の `FANFARE`、効果音の音量）が鳴ってから、BGMがボーナスの曲の頭から始まります。BIG中・大当たりのラウンド中は液晶の背景が機種の色の夜空に変わり（ASTRALは紺、AURORAは紫がかったピンク）、光の筋が回り、花火と紙吹雪が続き、背景の動きも速くなります。キャラクター（ソラ・ハナ）はボーナス中ずっと曲に合わせて踊り（左右にステップして跳ね、腕を交互に上げる、きらめき付き）、ベルなどの反応のあとはまた踊りに戻ります。BIGの枠は金のふちと光る文字に、払い出した枚数のゲージ付きにしました。ボーナスの終わりには「BIG BONUS 終了」「○枚」（パチンコは「大当たり終了」「○玉」）を紙吹雪と金色に流れるLEDで約3秒出します。演出は結果が出たあとにだけ出るので当たりの予告にはなりません。点滅は1秒に3回までです。控えめな演出では光と動きを弱く・遅くし（LEDは点滅を呼吸に）、動きを減らす設定ではフラッシュ・花火・紙吹雪を出さず、文字を止めて表示します。
- Space：発射／レバー、B：MAX BET、1・2・3：各リール停止（入力欄、ボタン、ダイアログを操作中は無効）。
- スマートフォンで盤面のレバー・MAX BET・停止ボタンやパチンコのボタンを素早く続けてタップしても、ダブルタップと見なされて画面が拡大・縮小しないようにしています（指でのスクロールと2本指での拡大はそのまま使えます）。
- 筐体はオリジナルのAI生成イラスト（`assets/aurora.webp`・`assets/astral.webp`、液晶とリール窓を透過）。その下に液晶（`lcd-scenes.js` の絵を使った舞台を動かす、保留ランプは液晶の左下）とリールを、上に玉・ガラスの反射をCanvas 2Dで描画。釘はプログラムでは描かず、筐体イラストに描かれた金色の釘を使います（`engine.js` の `NAILS` が、イラストに見えている金の釘約420本の位置・半径を部品として持ち、玉はそのすべてに当たります。液晶の左下に斜めに並ぶ3本の釘の列は、絵の列に沿って隙間なく並べた道釘で、玉は列の上を転がってヘソのほうへ流れます。液晶の屋根に重なる飾りの粒だけは屋根の一部として扱います。絵の釘の並びは実機ほど整っていないので、玉が釘の間に乗って止まったときは、少しのあいだ釘に当たる太さを細めて狭い間からこぼれ落ちるようにしています）。玉は小さめ（半径4.5）の鏡面の鋼球で、上半分に照明、中央に手前の暗い部屋、縁にまわりの盤面の色が映り込み、鋭いハイライトと接地の影がつきます。手前の受け皿とパネル、中央手前のボタンはガラスより前にあるので、玉とガラスの反射はボタンに重ねず、ガラスの範囲だけに描きます。液晶の数字は縁取りと立体感のある書体で、回転中は縦にスクロールして残像がつき、減速して止まると小さく弾みます（どの数字で止まるかは抽選結果だけで決まり、そろいそうな数字の前で遅くなる演出はしません）。液晶の背景は実機の待機・変動画面のように、約7秒ごとに別の舞台へ切り替わり（光が横切るつなぎ）、それぞれの舞台で雲・鯨・列車・波などが動き、花びらが舞い、流れ星や光の筋が動きます。抽選中は背景の動きが速くなります（当たり外れに関係なくすべての抽選で同じ）。控えめな演出がONのときは動きを少し遅く・光を弱くします（場面切り替えの光は出さない）。端末の「視差効果を減らす（動きを減らす）」設定では、背景（1枚の静止画）・スクロール・弾み・LEDの明滅を止めます。効果音は `sound.js` がWeb Audioでその場で合成します（音声ファイルなし）。釘に当たる音は、実機で耳に届く音の成り立ちをもとに作っています。真ちゅうの釘（太さ約1.8mm）は細すぎて自分ではほとんど空気を鳴らさず、振動が盤面に伝わって盤面が鳴り、それを前面の2枚のガラス越しに聞くので高い音が丸くなります。そのため、盤面の短い響き（約0.5〜2.3kHz）の「コツッ」を中心に、釘の響き（約1.9〜2.7kHz）を小さく重ね、当たった瞬間のクリックもガラスで丸めています（音の重心は約1.3kHz。最初の版は約3.5kHzで高すぎました）。釘ごとに高さが少しずつ違い、当たった速さで音量と明るさが変わり（弱いと鈍く小さく、強いと少し明るく大きく）、玉の位置で左右に聞こえます。ほかに、発射のハンマーの音とレールを転がって上る音、液晶まわりの枠に当たる音、ヘソ入賞の「カコン」とチャイム、払い出しの玉が受け皿に流れ込む「ジャラジャラ」（スタート入賞3玉・アタッカー8玉）、アウト穴に落ちる音、液晶の回転音と停止音、リールの回転音、停止ボタンの音、メダルの払出音。小役の当たりの音は短く控えめにしています（ボーナスの始まりだけファンファーレが鳴ります）。BGMは `music.js` がその場で合成するオリジナル曲（音声ファイルなし）で、AURORAは明るいポップ（通常）・Bマイナーの速い曲（リーチ）・ブラスの速い曲（大当たりのラウンド中）、ASTRALは星空のような穏やかな曲（通常）・速いダンス曲（BIG中）に切り替わります。曲が変わるのは画面にリーチ・大当たり・BIGが出ているときだけなので、当たりの予告にはなりません。休憩・記録の表示中とタブを離れたときは止まります。設定で効果音とBGMの音量を別々に変えられ（BGMは0で消音）、音量はこのブラウザに保存します。右上の「サウンド」で全部の音をON／OFF。音は初期OFF、光と動きを抑える設定は初期ON。

## ミニキャラ素材（2026-10-26）

`assets/navigator-portraits.webp` は、承認済みの筐体・液晶の世界観と既存キャラの配色を参考に生成した透明背景のオリジナルイラストです（4列×2行、上段ソラ・下段ハナ）。元のPNG（約3.1MB）を同じ大きさのWebP（約0.8MB）にして読み込みを軽くしました。描画時に各セルを切り出し、表情は0.18秒で重ねて切り替え（動きを減らす設定ではすぐ切り替え）、しゃべっている間は声に合わせて小さく弾みます。
