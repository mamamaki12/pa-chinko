# REEL ROOM v0.3.0

無料のパチンコ／パチスロ・シミュレーションWebアプリ。オリジナル機のパチンコ「AURORA」とパチスロ「ASTRAL」を収録しています。実在機の映像・音源や抽選仕様は使用していません。治療効果は検証していません。

## 起動

Node.js（検証用）とPython 3だけで利用できます。外部パッケージ、API、フォント配信は不要です。

```sh
npm start
# http://localhost:3000
npm test
npm run check
```

## 操作・機能

- パチンコ：発射ボタンで連続発射／停止。強度25〜100%（初期45%）。玉は外周レールを上り、強度に応じた位置で盤面に出ます（弱いと左、強すぎると右に流れて入賞しにくい）。ちょうどよい強さでのスタート入賞は打った玉の約6〜7%（250玉で約16回転）で、実機の甘デジの回り方に合わせています。重力、釘・外周・中央液晶・液晶上の屋根・入賞口へ寄せる透明なガイドとの衝突を固定120Hzで計算。発射に小さなばらつきがあります。スタート入賞で3玉。1/99の大当たりは実機のようなラウンド制で、右下の大入賞口（アタッカー）が開き、発射強度を強くした右打ちで入れた玉1つにつき8玉を払い出します（1ラウンドは10個入るか30秒で閉じ、2秒あけて次へ。4ラウンドで最大320玉）。液晶にラウンド・カウントと「右打ち ▶」を表示し、ふだんの遊技で発射強度を70%以上にすると、実機のように液晶へ「◀ 左打ち」を出します。大当たり中は保留の抽選を待ちます。抽選は最大4つ保留し、液晶左下の4つのランプで表示（5つ目以降の入賞は3玉のみ）。変動時間は保留数で変わり（外れ：保留0で5秒、1〜2で4秒、3以上で2.5秒）、当たりと外れの約1/15でリーチ（左右の数字がそろい、中央がゆっくり回る）。リーチの延長は「控えめな演出」または動きを減らす設定で2.5秒、それ以外は4秒。保留ランプは1色で当たりを予告せず、リーチ外れの中央は1つ違いの数字で止めません。リーチの途中で液晶に「PUSH!」が出て、台の中央手前のボタン（チャンスボタン）が光ります。ボタンをタップ／クリック（またはEnterキー）すると中央の数字が止まって結果が出ます（押さなくても3.5秒で自動で止まります）。ボタン演出は当たり・外れに関係なくすべてのリーチで同じように出るので、当たりの予告にはなりません（結果は抽選のときに決まっていて、押し方では変わりません）。遊技台の機構を簡略化した独自仕様です。
- パチスロ：筐体イラスト（`assets/astral.webp`）はそのままに、リール窓のまわりだけを実機風に `slot-view.js` で描画します（1本に3コマ見えるリール、左のメダリオンにBETランプ3・2・1、右にSTART／REPLAY／WAITランプ、窓の下のプレートに7セグのCREDIT・PAYOUT）。リール帯は空色の紙に雲と星を刷った柄で、図柄（実機の写真を参考に、リール幅いっぱいの太い7に筐体の女の子の絵を刷り込み、金と紺のふち。金のふちの黒いBARに赤い文字、青い宝石のリプレイ、横に広い金のベル、切ったスイカ、つやのあるチェリー））ごと一度だけ画面外に描き、毎フレーム細い帯に切って円筒に巻き付けるので、実機のドラムのように上下で図柄が曲がって暗くなります。回転中は縦に流れるブレ、背面の3つのランプで各段が明るく、ドラムの縁・窓枠の影・ガラスの映り込みもつけています。ランプはメダリオンにはめた丸いレンズで、消灯中はくすんだ黒、点灯するとその色に光ります（WAITは4.1秒ウェイト中に点灯）。プレートの文字の書体は筐体の彫り文字に合わせた Cinzel／Cinzel Decorative（SIL Open Font License、`assets/fonts/` に同梱）です。筐体に描かれたレバー（左の黒いノブ）・MAX BET（右の銀のドーム）・停止ボタンを直接タップ／クリックして操作します（パチスロでは画面下の操作ボタンは出しません）。押すとへこみ、押せるときは光ります。盤面のレバー・MAX BET・停止ボタンは直接タップ／クリックでき、押すとへこみ、レバーは下に倒れます。MAX BETで3枚を投入（未投入でレバーを叩くと自動で投入）。レバーを叩くと、その時点で役を抽選します（独自の表、16384分の：BIG 40、スイカ 200、チェリー 400、ベル 1800、リプレイ 2240、残りは外れ）。実機と同じく1ゲームは4.1秒より短くならず、前のゲームの開始から4.1秒たつ前にレバーを叩くと、役はその場で抽選し、リールは4.1秒たってから回ります（ウェイト）。個別STOPを押すと、その時に中央へ来る図柄から最大4コマ（約0.2秒以内）すべらせて、リールを減速させずにピタッと止め、成立した役を中央1ラインに引き込み、成立していない役は外します。リールは左・中・右で別の21図柄配列。ベルとリプレイはどこで押しても揃い、7・スイカ・左チェリーは押す位置によって取りこぼします（持ち越しなし）。配当は7揃いでBIGボーナス（実機のAタイプのように、7揃い自体の払い出しはなく、BIG中は毎ゲームどこで押しても15枚のベルが揃い、合計150枚を払い出すと終了。液晶に「BIG BONUS」と獲得枚数を表示）、スイカ10枚、ベル8枚、左チェリー2枚、リプレイは次ゲームのメダル不要、BARは配当なし。払い出しは実機のようにPAYOUTとCREDITを1枚ずつ数えて増やし（1秒に12枚、動きを減らす設定では一度に）、数え終わるまで次のゲームは始められません。BIG以外のボーナス、AT、RTは未実装。ボーナスの持ち越しと告知ランプは、揃えるまで遊び続けたくなる仕組みなので入れていません。
- 液晶のキャラクター：AURORAには「ハナ」（ピンクの髪・花飾り）、ASTRALには「ソラ」（銀青の髪・星飾り）が液晶の中にいて、状況に合わせて動き、液晶にセリフの文字だけを出してしゃべります（吹き出しの枠はなく、白い文字にキャラの色のふちどり。`lcd-character.js` の反応制御と `navigator-art.js` の描画。銀青・星飾りのソラ、ピンク・花飾りのハナを、繊細な髪の流れと柔らかな顔のオリジナルイラストに更新。透明な画像に通常・喜び・驚き・休憩の4表情を収録し、足元の位置を揃えて短く重ねながら切り替えます。ときどきまばたきし、しゃべっている間は文字送りに合わせて口が開いたり閉じたりします（句読点では閉じる）。頭・腕・足・羽・髪・スカートがパーツごとに動き、反応ごとに動きが変わります（見守り：画面のほうへ首をかしげて足をぶらぶら、うなずき、手を振る：上げた腕を肩から振る、拍手：腕を上げ下げして小さく跳ねる、喜び：腕を上げてぴょんぴょん跳ね、跳ぶたびに足が外へ出て着地でつぶれる・大当たりやBIGは最初にくるっと1回転して前に出る、リーチ・大当たり開始：驚いて頭をのけぞらせて跳ね、そのあと足踏みして手が震える、おじぎ、休憩中はうとうと首をかたむける）。しゃべっている間は首と手も小さく動きます。何もないときは6.5秒ごとくらいに、ぴょんと跳ねる・左右に揺れる・くるっと回る・伸び・リズムに乗る・振り向くといった小さな仕草をします（抽選中・おしゃべり中はしない）。まわりには、喜び・拍手のきらめき、リーチ・大当たり開始の「！」、手を振るときの音符、休憩中の「z」が出ます。画像の読込中・読込失敗時は従来のCanvasキャラを表示）。待機中はゆっくりした揺れ・ときどき雑談（深呼吸や水分補給など）、抽選中・リール回転中は画面を見守り、リーチ・当たり・はずれ、パチスロのリプレイ・ベル・チェリー・スイカ・7揃い（BIG）、休憩前・休憩中・おかえり・終了のあいさつに反応します。反応は結果が出たあと（またはリーチが出たあと）だけで、レバーや変動開始の反応はどのゲームでも同じ候補から選ぶので、当たりの予告にはなりません。惜しさを強調するセリフや、続けて遊ぶようあおるセリフは入れていません。当たりのあとは休憩を勧める一言が続きます。サウンドONのときは、文字送りに合わせて合成の短い声（ピコピコ音）が鳴ります。控えめな演出ではきらめきと跳ね方を弱く、動きを減らす設定では体の動き・まばたき・口パク・仕草を止め、セリフを一度に表示します。
- 台の部品：台を1枚の絵としてではなく、要素ごとの部品として `cabinet-parts.js` で管理します。AURORAはLED・釘・ガイドレール・START入賞口・アタッカー・チャンスボタン・発射ハンドル・保留ランプ・液晶・盤面ガラス、ASTRALはLED・液晶・リール窓・リール・ベット/START/REPLAY/WAITランプ・クレジットと払い出しの表示器・レバー・MAX BET・停止ボタン。どの部品も id・種類・名前・形（位置）・状態（表示・点灯・開閉）を持ち、`parts.set('attacker',{open:true})`・`parts.set('nail-012',{visible:false})`（その釘は当たり判定からも外れる）のように id・種類・グループで切り替えられます。描画とパチスロのランプの点灯はこの状態を読みます。ページを `?parts` 付きで開くと、全部品の輪郭とidを台の上に表示します。
- 台のLED：筐体イラストに描かれたLEDの部分（AURORA 21か所、ASTRAL 16か所）を `cabinet-leds.js` の多角形で部品として切り出し、その中の明るく色のついた画素だけを点灯・消灯させます（画面全体を光らせる演出はやめました）。部品ごとに 消灯 / 点灯 / 点滅 / 呼吸（ゆっくり明滅） / 流れる光 と明るさ・色（虹色も）を持ち、id・グループ（上・サイド・前面など）・全部で指定できます。場面ごとの光り方（待機・抽選中・リーチ・ボタン・大当たり・払い出し・リール回転・リプレイ・BIG）も同じファイルの表で決めています。点滅は1秒に3回より速くしません。控えめな演出では点滅を呼吸に変えてゆっくりにし、動きを減らす設定では止めます。設定の「台のLED」で 演出に合わせて光る / いつも点灯 / 消灯 を選べます。ページを `?leds=reach` のように開くと、その場面の光り方のまま確認できます。
- Space：発射／レバー、B：MAX BET、1・2・3：各リール停止（入力欄、ボタン、ダイアログを操作中は無効）。
- 筐体はオリジナルのAI生成イラスト（`assets/aurora.webp`・`assets/astral.webp`、液晶とリール窓を透過）。その下に液晶（`assets/lcd-illustration.jpg`をゆっくり移動・拡大、保留ランプは液晶の左下）とリールを、上に玉・ガラスの反射をCanvas 2Dで描画。釘はプログラムでは描かず、筐体イラストに描かれた金色の釘を使います（`engine.js` の `NAILS` が、イラストの金色の粒から玉が通れる間隔で選んだ約200本の位置・半径を部品として持ち、玉はそこに当たります。イラストの粒は実際の釘より密なので、選ばれなかった粒は飾りとして玉が通り抜けます）。玉は小さめ（半径4.5）の鏡面の鋼球で、上半分に照明、中央に手前の暗い部屋、縁にまわりの盤面の色が映り込み、鋭いハイライトと接地の影がつきます。手前の受け皿とパネル、中央手前のボタンはガラスより前にあるので、玉とガラスの反射はボタンに重ねず、ガラスの範囲だけに描きます。液晶の数字は縁取りと立体感のある書体で、回転中は縦にスクロールして残像がつき、減速して止まると小さく弾みます（どの数字で止まるかは抽選結果だけで決まり、そろいそうな数字の前で遅くなる演出はしません）。液晶の背景は実機の待機・変動画面のように、イラストの中を寄ったり流したりしながら約7秒ごとに場面が切り替わり（光が横切るつなぎ）、2層の雲が流れ、花びらが舞い、流れ星や光の筋が動きます。抽選中は背景の動きが速くなります（当たり外れに関係なくすべての抽選で同じ）。控えめな演出がONのときは動きを少し遅く・光を弱くします（場面切り替えの光は出さない）。端末の「視差効果を減らす（動きを減らす）」設定では、背景（1枚の静止画）・スクロール・弾み・LEDの明滅を止めます。効果音は `sound.js` がWeb Audioでその場で合成します（音声ファイルなし）。釘に当たる音は、実機で耳に届く音の成り立ちをもとに作っています。真ちゅうの釘（太さ約1.8mm）は細すぎて自分ではほとんど空気を鳴らさず、振動が盤面に伝わって盤面が鳴り、それを前面の2枚のガラス越しに聞くので高い音が丸くなります。そのため、盤面の短い響き（約0.5〜2.3kHz）の「コツッ」を中心に、釘の響き（約1.9〜2.7kHz）を小さく重ね、当たった瞬間のクリックもガラスで丸めています（音の重心は約1.3kHz。最初の版は約3.5kHzで高すぎました）。釘ごとに高さが少しずつ違い、当たった速さで音量と明るさが変わり（弱いと鈍く小さく、強いと少し明るく大きく）、玉の位置で左右に聞こえます。ほかに、発射のハンマーの音とレールを転がって上る音、液晶まわりの枠に当たる音、ヘソ入賞の「カコン」とチャイム、払い出しの玉が受け皿に流れ込む「ジャラジャラ」（スタート入賞3玉・アタッカー8玉）、アウト穴に落ちる音、液晶の回転音と停止音、リールの回転音、停止ボタンの音、メダルの払出音。当たりの音は短く控えめにしています。BGMは `music.js` がその場で合成するオリジナル曲（音声ファイルなし）で、AURORAは明るいポップ（通常）・Bマイナーの速い曲（リーチ）・ファンファーレ（大当たりのラウンド中）、ASTRALは星空のような穏やかな曲（通常）・速いダンス曲（BIG中）に切り替わります。曲が変わるのは画面にリーチ・大当たり・BIGが出ているときだけなので、当たりの予告にはなりません。休憩・記録の表示中とタブを離れたときは止まります。設定で効果音とBGMの音量を別々に変えられ（BGMは0で消音）、音量はこのブラウザに保存します。右上の「サウンド」で全部の音をON／OFF。音は初期OFF、光と動きを抑える設定は初期ON。
- 5／10／15分の自動休憩。休憩・設定・記録の表示中は遊技と時間を凍結。タブを離れたときも中断。発射の再開は手動です。
- 「今日はここまで」→「記録して終了」で日時、遊技時間、機種、消費数、払出数をこのブラウザのlocalStorageに直近50件保存。休憩画面では任意で「続けたい気持ち」（1〜5）と200字までのメモも残せます（入力しなくても終了できます）。JSON出力・削除に対応。終了せずタブを閉じると今回の記録は残りません。ブラウザ間の同期、My海馬への自動同期はありません。
- 左の「THIS WEEK」に今週（月曜0時から）の遊技時間を表示。設定で1週間の目安（1〜7時間）を決めると、超えたときに控えめなお知らせを1回だけ出します。遊技は止めず、休憩や終了を選びやすくするための表示です。プレイ記録には直近4週の合計・回数・気持ちの平均を表示。集計は保存済みの記録から計算するため、記録を削除すると合計も消えます。
- 現金、課金、換金、広告、外部送信はありません。残高はリロードで初期値に戻ります。

## 対象と限界

依存症の治療・回復を保証するものではありません。リアルな遊技表現は遊技欲求を強める可能性があります。欲求が強まる場合は中断してください。長時間継続を促すミッションや通知は設けていません。

本版は動作するオリジナルの試作です。実機相当の3Dモデル、映像演出、音響、機構の完全再現には未到達です。スマートフォンを含むCanvas対応ブラウザ向け。遊技台は画面の高さに合わせて大きく表示します（パソコンでは台と操作ボタンが1画面に収まる大きさ、スマートフォンでは画面の幅いっぱい）。

筐体と液晶のイラストはAIで生成したオリジナル画像で、実在の機種・作品のロゴやキャラクターではありません。元画像はMy海馬（`20_開発/進行中/pa-chinko/`）に保存しています。

## ミニキャラ素材（2026-10-26）

`assets/navigator-portraits.webp` は、承認済みの筐体・液晶の世界観と既存キャラの配色を参考に生成した透明背景のオリジナルイラストです（4列×2行、上段ソラ・下段ハナ）。元のPNG（約3.1MB）を同じ大きさのWebP（約0.8MB）にして読み込みを軽くしました。描画時に各セルを切り出し、表情は0.18秒で重ねて切り替え（動きを減らす設定ではすぐ切り替え）、しゃべっている間は声に合わせて小さく弾みます。

`assets/navigator-faces.webp`（約14KB）は、まばたきと口パク用の顔パーツです。各表情のセルを元に、目を閉じた顔（通常・驚き）、口を開けた顔（通常・休憩）、口を閉じた顔（喜び・驚き）を作り、変えた部分だけを切り出しています。描画時はセルの同じ位置に重ねるので、ほかの部分は元の絵のままです。手足・頭はパーツごとに動きます（`navigator-rig.js`）。表情ごとの絵に、首・肩・手・腰・足先・羽の付け根の位置を記録し、絵を細かい網目（33×43の点）に分けて、頭は首、腕は肩、足は腰、羽は付け根を中心にそれぞれ曲げます。長い髪とスカートは、体から離れた部分ほど大きく、波のようになびきます。網目はWebGLで描き、使えないときは上半身をしならせる動きだけにします。腕を振る・腕を上げて喜ぶ・拍手・足を蹴り上げる・足をぶらぶらさせる・首をかしげる・うなずく・羽ばたく、などを反応ごとに組み合わせ、さらに足元を中心に伸び縮み・回転させています。
