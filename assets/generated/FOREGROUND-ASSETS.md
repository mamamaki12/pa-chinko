# 前景の素材4点（2026-11-08）

My海馬「2026-10-29_背景とリーチ演出の生成プロンプト」第6-2節。参照3の液晶の絵を添えて画像生成ツールで制作。

| PNGのID | 内容・配置 | 原本の実寸 |
| --- | --- | --- |
| fg-cloud-bank | 白い雲の帯。下側は柔らかく透ける | 2048×768 |
| fg-sakura-branch | 右上から伸びる桜の枝、手前の花をぼかす | 1536×1024 |
| fg-crystal | 左下から伸びる紫の水晶、根元をぼかす | 1254×1254 |
| fg-vine | 上から垂れる緑のつると白・金の小花 | 1536×1024 |

- すべて透明RGBA PNG。水晶は指定1024×1024より大きい生成原本を加工せず保存。
- PNG読み込み・透明度を確認。Chromiumで明色／暗色背景へ重ねて表示確認済み。桜とつるの周囲には淡い発光・ぼかしがあり、暗い背景で目立つ。
- 桜の右上、つるの上端、水晶の左下は画面外へ続く構図。アプリでもその辺を液晶の縁に合わせ、透明余白を個別に切り詰めない。
- 雲は横に並べたときの継ぎ目を合わせた素材ではない。第6-3節のtile-cloudseaとは別。
- 今回は素材の納品のみ。ゲーム登録・縮小WebP化・dist反映は未実施。通常のアルファ合成で前景へ重ね、中央の数字を覆い過ぎない大きさと位置に調整する。
- 控えめな演出では移動と光を弱く、動きを減らす設定では静止画にする。
- 次の範囲は第6-3節：横につなげる雲海・オーロラ・星空・水面の4点。
