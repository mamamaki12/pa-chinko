# 横に繰り返す背景4点（2026-11-08）

My海馬「背景とリーチ演出の生成プロンプト」第6-3節。参照3の液晶の絵を添えて生成し、ユーザー指定でPythonの画像処理による継ぎ目補正を実施。

| 完成版 | 寸法 | 形式・使い方 |
| --- | --- | --- |
| tile-cloudsea.png | 2048×512 | RGBA。雲より上は透明、通常のアルファ合成 |
| tile-aurora.png | 2048×768 | RGB。黒背景、screen合成 |
| tile-stars.png | 2048×1024 | RGB。不透明の紺色の星空 |
| tile-water.png | 2048×512 | RGB。不透明の水面 |

## 原本と補正

- 未加工の生成原本4点は `tile-originals/` に保存。雲海・水面2172×724、オーロラ2048×768、星空1774×887。
- `python scripts/make-background-tiles.py` で再作成（PillowとNumPyが必要）。左右12.5%を滑らかに重ね、透明画像はアルファを掛けた色で処理して色にじみを防ぐ。繰り返し位置を移し、指定寸法にリサイズして最後に左右の端を一致させる。
- 星空などはリサイズで拡大されている。原本以上の細部を復元したものではない。雲海・水面は指定の横長比率に合わせている。
- 水面原本中央の細い不連続は48px幅の補間で補正。その部分は波の細部が少し柔らかくなる。
- オーロラのほぼ黒い霞は階調補正で黒に戻す。光の近くには暗い色が残るが、黒の矩形ではなく光として合成する。

## 検証と組み込み

- 全4点のPNG読み込み・寸法・形式を確認。左右端の全画素が一致（雲海はアルファも含む）。Chromiumで2枚並べた繰り返し表示を目視確認。
- 左右方向のみの繰り返し用。上下方向の継ぎ目は保証しない。発光や波の模様の繰り返しは見えるため、アプリではゆっくり流す。
- 今回は素材納品まで。ゲーム登録・WebP変換・dist反映は未実施。縮小WebP化後にも継ぎ目を確認し、各タイルを同じ倍率・整数座標で隙間なく並べる。
- 控えめな演出では速度と光量を抑え、動きを減らす設定では静止画にする。
- 次の未作成候補は第7節の `fx-butterfly`（開いた羽・半閉じの羽）。旧plate/btn系は指示書で作成不要、動画は作成可能な場合だけ。
